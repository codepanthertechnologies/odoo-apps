# Smart Duplicate Detection

Realtime duplicate detection for Contacts and Products in Odoo.

## Features

### Contact Duplicate Detection

- Email
- Mobile
- Phone

### Product Duplicate Detection

- Barcode
- Internal Reference (`default_code`)

## Key Highlights

- Realtime soft warnings
- No ValidationError blocking
- Lightweight ORM queries
- Case-insensitive email matching
- Phone normalization
- Ignore current record
- Ignore empty values
- Configurable settings
- Production-ready architecture

## Supported Versions

- Odoo 16
- Odoo 17
- Odoo 18
- Odoo 19

## Configuration

Go to:

Settings → Smart Duplicate Detection

Enable or disable individual checks.
